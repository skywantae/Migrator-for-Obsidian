# 네이버 블로그 → 옵시디언 마이그레이션 도구

네이버 블로그의 모든 글(공개/비공개, 이미지 포함)을 옵시디언 노트로 빠르게 변환하고, 자동으로 연결하는 GUI 도구입니다.

## 특징

- **고속 수집**: 글당 ~1초 (367개 약 6분)
  - 페이지 크롤링 대신 HTTP API 직접 호출
  - 이미지 8개 병렬 다운로드
  
- **자동 연결** (3가지 방식)
  - 카테고리 허브: 카테고리별 색인 노트 자동 생성
  - 태그 기반: 해시태그 공유 글끼리 링크
  - 본문 유사도: 제목+본문 텍스트 TF-IDF 유사도로 연결

- **원본 화질 이미지**: 썸네일이 아닌 900×1000+ 원본 다운로드

- **프라이버시**: 로그인은 크롬에서만 (쿠키 얻기 위함), 이후 HTTP API만 사용

- **Obsidian 친화적**
  - 자동 폴더 탐지 (옵시디언 설정에서 마지막 열었던 볼트 자동 선택)
  - 폴더 선택 대화상자 (경로 직접 입력 불필요)
  - YAML Frontmatter: title, date, category, tags, source
  - 이미지: `![[원본화질_이미지.jpg]]` 위키링크 형식

- **설정 저장**: 처음 한 번 입력 후 다음 실행부터 자동 복원

## 설치 및 실행

### 옵션 1: exe 파일 (권장, 파이썬 불필요)

```bash
naver_blog_migrator.exe
```

더블클릭하면 GUI 창이 뜹니다. 폴더 선택 → 옵션 체크 → [시작하기]

### 옵션 2: 소스 코드 실행

```bash
pip install -r requirements.txt
python naver_blog_migrator.py
```

## 사용 방법

1. **폴더 선택**: [폴더 선택] 버튼으로 옵시디언 볼트 안 폴더 지정
   - 기본값: 옵시디언에서 마지막 열었던 볼트 하위 `네이버블로그` 폴더
   - 옵시디언 볼트 안에 저장하면 옵시디언에서 바로 새로고침됨

2. **가져올 글**: 전체 또는 최신 N개

3. **옵션**:
   - ☑ 이미지를 원본 화질로 저장 (1.25MB+ 원본)
   - ☑ 카테고리·관련 글 자동 링크 만들기

4. **[시작하기]** → 크롬 로그인 (40초~) → 자동 수집

## 수집 원리

- **목록**: `PostTitleListAsync.naver` (한 번에 30개)
- **본문**: `PostView.naver?...&redirect=Dlog&widgetTypeCall=true` (HTML 직접)
- **카테고리**: `m.blog.naver.com/api/blogs/{id}/category-list` (JSON)
- **태그**: `BlogTagListInfo.naver` (여러 글 묶어서 한 번에)

Obsidian의 "Naver Blog Importer" 플러그인과 동일한 고속 방식을 구현했습니다.

## 파일 구조

```
obsidian_export/
├── 123456789_제목.md          # 글 (YAML Frontmatter 포함)
├── 카테고리 - 개발.md           # 카테고리 허브 (자동생성)
├── 카테고리 - 일상.md
├── attachments/
│   ├── 123456789_1.jpg       # 다운로드한 이미지
│   ├── 123456789_2.jpg
│   └── ...
├── posts_index.json           # 메타데이터 캐시 (재실행용)
├── category_map.json          # 카테고리 매핑 캐시
└── post_urls.json             # 글 목록 캐시
```

## Frontmatter 예

```yaml
---
title: "티벳 여행 8일차 - 청두"

```

## 주의사항

### 처음 실행 시
- 로그인 후 **로그인이 확인되면 자동으로 다음 단계로 넘어갑니다** (40초 기다릴 필요 없음)
- 크롬 창은 로그인 세션(쿠키)을 얻기 위해서만 필요함

### 재실행 시
- 이미 처리된 글(같은 logNo)은 자동 건너뜀
- 중간에 중단했다면 다시 실행하면 **남은 글부터 이어서** 진행

### 이미지 저장 용량
- 글당 이미지 평균 10~50장
- 원본 화질은 0.4~1.2MB/장 → 전체 수 GB 가능
- 필요시 설정에서 "이미지 저장" 체크 해제

### 스킨별 HTML 구조 차이
- 신버전(SmartEditor ONE)과 구버전(SmartEditor 2) 스킨이 다를 수 있음
- 본문/제목/날짜가 비어 나오면 크롬 F12로 실제 셀렉터를 확인하고 `naver_blog_migrator.py`의 `SELECTORS` 딕셔너리를 수정
