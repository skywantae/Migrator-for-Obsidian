# 옵시디언 마이그레이션 도구

네이버 블로그와 노션(Notion)의 글을 옵시디언 노트로 옮기고, 자동으로 연결하는 GUI 도구입니다.

창을 열면 탭이 두 개 있습니다. 필요한 쪽을 골라 쓰세요.

---

## 네이버 블로그 탭

- **고속 수집**: 글당 약 1초 (367개 약 6분)
  - 페이지 크롤링 대신 HTTP API 직접 호출
  - 이미지 8개 병렬 다운로드
- **원본 화질 이미지**: 썸네일이 아닌 900×1000+ 원본 다운로드
- **자동 연결** 3가지
  - 카테고리 허브: 카테고리별 색인 노트 자동 생성
  - 태그 기반: 해시태그를 공유하는 글끼리 링크
  - 본문 유사도: 제목·본문 TF-IDF 유사도로 연결
- **프라이버시**: 로그인은 크롬에서만 (쿠키를 얻기 위함), 이후엔 HTTP API만 사용

### 수집 원리

| 대상 | 엔드포인트 |
| --- | --- |
| 목록 | `PostTitleListAsync.naver` (한 번에 30개) |
| 본문 | `PostView.naver?...&redirect=Dlog&widgetTypeCall=true` (HTML 직접) |
| 카테고리 | `m.blog.naver.com/api/blogs/{id}/category-list` (JSON) |
| 태그 | `BlogTagListInfo.naver` (여러 글 묶어서 한 번에) |

Obsidian의 "Naver Blog Importer" 플러그인과 같은 고속 방식입니다.

## 노션 탭

**읽기 전용입니다.** 노션의 데이터를 수정하거나 지우지 않습니다.
(호출하는 API는 `GET /users`, `POST /search`, `GET /blocks/.../children`,
`POST /databases/.../query` 뿐이며 쓰기·삭제 호출은 코드에 존재하지 않습니다.)

- **계층 구조 유지**: 하위 페이지가 있으면 같은 이름의 폴더가 옆에 생깁니다 (노션 공식 내보내기와 같은 모양)
- **데이터베이스**: 항목 하나하나가 노트가 되고, 속성은 Frontmatter로 들어갑니다. 색인 노트도 함께 만듭니다
- **첨부 전부**: 이미지 · 파일 · PDF · 동영상 · 오디오를 `attachments/`로 내려받습니다
- **페이지 링크**: 노션의 페이지 멘션과 하위 페이지 링크가 옵시디언 위키링크 `[[...]]`로 바뀝니다

### 지원하는 블록

문단 · 제목1~3 · 글머리 기호 · 번호 목록 · 할 일 · 토글 · 인용 · 콜아웃 · 코드 ·
수식 · 구분선 · 이미지 · 파일 · PDF · 동영상 · 오디오 · 북마크 · 임베드 · 표 ·
다단(컬럼) · 동기화 블록 · 하위 페이지 · 페이지 링크

서식은 **굵게** · *기울임* · ~~취소선~~ · `코드` · 밑줄 · 링크 · 인라인 수식까지 옮깁니다.
토글은 옵시디언의 접이식 콜아웃(`> [!note]-`)이 됩니다.

### 처음 한 번만: 노션에서 권한 주기

노션 통합(Integration)은 **명시적으로 연결한 페이지만** 볼 수 있습니다.
API로는 권한을 줄 수 없어서 노션에서 직접 해주셔야 합니다.

1. https://www.notion.so/my-integrations 에서 통합을 만들고 토큰을 복사
   (`ntn_` 또는 `secret_` 으로 시작)
2. 노션에서 옮기고 싶은 **최상위 페이지**를 열기
3. 우측 상단 `···` → **연결(Connections)** → 만든 통합 이름 추가

하위 페이지와 데이터베이스는 자동으로 따라옵니다. 최상위 몇 개만 해주면 됩니다.

토큰을 넣고 **[연결 확인]** 을 누르면 접근 가능한 항목이 몇 개인지 바로 알려줍니다.
0개로 나오면 3번이 아직 안 된 것입니다.

## 설치 및 실행

### 옵션 1: exe 파일 (파이썬 불필요)

`naver_blog_migrator.exe` 를 더블클릭하면 창이 뜹니다.

### 옵션 2: 소스 코드

```bash
pip install -r requirements.txt
python naver_blog_migrator.py
```

## 사용 방법

1. **탭 선택**: 네이버 블로그 / 노션
2. **저장 위치**: [폴더 선택] 버튼으로 옵시디언 볼트 안 폴더 지정
   - 옵시디언에서 마지막에 열었던 볼트를 자동으로 찾아 기본값으로 넣습니다
   - 볼트 안이면 초록색, 밖이면 주황색으로 알려줍니다
3. **옵션 체크** 후 **[시작하기]**

설정은 자동으로 저장되어 다음 실행 때 그대로 복원됩니다.

## 파일 구조

```
볼트/
├── 네이버블로그/
│   ├── 123456789_제목.md
│   ├── 카테고리 - 개발.md          # 자동 생성 색인
│   ├── attachments/
│   │   └── 123456789_1.jpg
│   └── posts_index.json
└── 노션/
    ├── 업무 노트.md
    ├── 업무 노트/                  # 하위 페이지들
    │   ├── 회의록.md
    │   └── 회의록/
    │       └── 2026 상반기.md
    ├── 독서 기록.md                # 데이터베이스 색인
    ├── 독서 기록/
    │   └── 사피엔스.md             # 항목 = 노트
    └── attachments/
```

## Frontmatter 예

네이버 블로그:

```yaml
---
title: "티벳 여행 8일차 - 청두"
date: 2026-06-14
category: "2026_중국"
tags: ["여행", "중국", "티벳"]
source: https://blog.naver.com/skywantae/224315502175
---
```

노션 (데이터베이스 속성이 그대로 들어갑니다):

```yaml
태그: ["역사", "인류학"]

별점: 5
완독: true
source: https://notion.so/...
notion_id: 1ceed4c2-66d2-488d-b106-a3432664e5ac
---
```

## 주의사항

### 다시 실행할 때
- 이미 있는 노트는 건너뜁니다. 중간에 멈췄어도 다시 실행하면 이어서 진행합니다.

### 저장 용량
- 네이버: 글당 이미지 10~50장, 원본 화질은 장당 0.4~1.2MB → 전체 수 GB 가능
- 노션: 첨부가 많으면 마찬가지입니다. 필요 없으면 옵션에서 체크를 해제하세요.

### 노션 속도
- 노션 API 제한(초당 3회)을 지키느라 노트 하나에 1초쯤 걸립니다. 470개면 약 8분입니다.
- 첨부 파일은 별개로 8개씩 동시에 받습니다.

### 토큰 보관
- 노션 토큰은 `settings.json` 에 평문으로 저장됩니다. 이 파일은 `.gitignore` 에 들어 있어
  깃에 올라가지 않지만, PC를 공유한다면 주의하세요.

### 네이버 스킨별 HTML 차이
- 신버전(SmartEditor ONE)과 구버전(SmartEditor 2) 구조가 다를 수 있습니다.
- 본문·제목·날짜가 비어 나오면 크롬 F12로 실제 셀렉터를 확인하고
  `naver_blog_migrator.py` 의 `SELECTORS` 를 수정하세요.
