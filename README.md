> *(브라우저에서 다운로드 후 바로 실행하시면 됩니다)*

네이버 블로그 · 노션(Notion) · 엑셀(.xlsx)의 내용을 **옵시디언 노트로 옮기는** GUI 도구입니다.

창을 열면 탭이 세 개 있습니다. 필요한 쪽을 골라 쓰세요.

- 로그인한 **본인 계정**의 자료만 가져옵니다. 남의 블로그나 워크스페이스는 대상이 아닙니다.
- 원본은 **읽기만** 합니다. 네이버 글도, 노션 페이지도, 엑셀 파일도 수정하거나 지우지 않습니다.

---

## 빠르게 시작하기

### 1. 무설치 실행 파일로 시작하기 (권장)
- [Releases 페이지](https://github.com/skywantae/Migrator-for-Obsidian/releases/latest)에서 **`obsidian_migrator.exe`** 를 다운로드하여 실행합니다.
- 파이썬이나 별도 라이브러리 설치가 전혀 필요하지 않습니다.

### 2. 소스 코드로 직접 실행 (개발자용)
```bash
pip install -r requirements.txt
python obsidian_migrator.py
```

### 사용 순서
1. 탭을 고릅니다 — **네이버 블로그** / **노션** / **엑셀**
2. **[폴더 선택]** 으로 옵시디언 볼트 안에 저장할 폴더를 지정합니다
   - 마지막에 열었던 볼트를 자동으로 찾아 기본값으로 넣어 줍니다
   - 볼트 안이면 초록색, 밖이면 주황색으로 알려 줍니다
3. 옵션을 확인하고 **[시작하기]**

설정은 자동 저장되어 다음 실행 때 그대로 복원됩니다. 중간에 멈춰도 다시 실행하면 이어서 진행합니다.

## 네이버 블로그 탭

### 준비물

없습니다. **[시작하기]** 를 누르면 크롬 창이 떠서 네이버 로그인을 기다립니다.
로그인하면 블로그 아이디를 자동으로 알아내고, 이후 수집은 전부 HTTP로 이뤄집니다.
(크롬은 로그인 쿠키를 얻기 위해서만 잠깐 씁니다)

### 하는 일

- **고속 수집** — 글 하나에 약 1초. 페이지를 열어 긁는 대신 네이버 내부 API를 직접 부릅니다
- **원본 화질 이미지** — 본문에 박힌 썸네일이 아니라 원본을 받습니다. 8개씩 동시에 내려받습니다
- **카테고리별 폴더** — 블로그의 카테고리 이름 그대로 폴더를 만들고 그 안에 글을 넣습니다
- **파일 이름은 글 제목 그대로** — 앞에 글 번호를 붙이지 않습니다
- **자동 연결 3가지**
  - 카테고리 허브 — 카테고리마다 색인 노트를 만들어 글을 모아 둡니다
  - 태그 기반 — 해시태그를 공유하는 글끼리 이어 줍니다
  - 본문 유사도 — 제목·본문의 TF-IDF 유사도로 비슷한 글을 이어 줍니다

### 스마트 증분 동기화 (신규 및 수정 포스팅만 업데이트)

- **이미 가져온 글 중 변경 없는 글은 건너뜀** — 수집 시간을 획기적으로 줄여 몇 초 만에 끝납니다.
- **신규 글 자동 감지** — 새로 작성한 글은 즉시 다운로드하여 옵시디언 노트로 생성합니다.
- **제목·카테고리 변경 감지** — 블로그에서 글 제목을 바꾸면 노트 이름과 볼트 내부 `[[링크]]`를 자동으로 고치고, 카테고리를 바꾸면 새 카테고리 폴더로 자동 이동합니다.
- **본문 내용 수정 감지** — 본문 해시(SHA-256)를 비교하여 본문이나 이미지가 수정된 포스팅을 감지하고 최신 내용으로 자동 갱신합니다 (최근 포스팅 정밀 검사 옵션).
- **같은 글 판단 기준**: 파일 이름이 아니라 본문 Frontmatter의 `source` 주소(`logNo`)로 판단하므로, 노트 이름을 마음대로 바꿔도 중복 다운로드되지 않습니다.

### 예전에 받아 둔 결과가 있다면

다시 실행하면 알아서 정리합니다. 변경 없는 글은 다시 내려받지 않으므로 몇 초면 끝납니다.

- 저장 폴더 최상위에 흩어져 있던 글 → 카테고리 폴더로 이동
- 이름 앞에 글 번호가 붙은 글 → 제목만 남기고 정리
- 이름이 바뀐 만큼 `[[링크]]` 도 함께 고칩니다

직접 쓴 노트와 `_` 로 시작하는 폴더, `attachments` 는 건드리지 않습니다.

### 수집 원리

| 대상 | 엔드포인트 |
| --- | --- |
| 목록 | `PostTitleListAsync.naver` (한 번에 30개) |
| 본문 | `PostView.naver?...&redirect=Dlog&widgetTypeCall=true` (HTML 직접) |
| 카테고리 | `m.blog.naver.com/api/blogs/{blogId}/category-list` (JSON) |
| 태그 | `BlogTagListInfo.naver` (여러 글 묶어서 한 번에) |

옵시디언 "Naver Blog Importer" 플러그인과 같은 고속 방식입니다.

## 노션 탭

### 준비물: 통합(Integration) 토큰

노션 통합은 **명시적으로 연결한 페이지만** 볼 수 있습니다.
API로는 권한을 줄 수 없어서 노션에서 직접 해주셔야 합니다. **처음 한 번만** 하면 됩니다.

1. 앱의 **[통합 만들기 열기]** 버튼을 누릅니다
   (또는 직접 <https://www.notion.so/my-integrations> 로 이동)
2. 통합을 새로 만들고 토큰을 복사합니다 — `ntn_` 또는 `secret_` 으로 시작합니다
3. 앱의 토큰 칸에 붙여넣습니다
4. 노션에서 **옮기고 싶은 최상위 페이지**를 엽니다
5. 우측 상단 `···` → **연결(Connections)** → 만든 통합 이름을 추가합니다

하위 페이지와 데이터베이스는 자동으로 따라옵니다. **최상위 몇 개만** 해주면 됩니다.

마지막으로 **[연결 확인]** 을 누르면 접근 가능한 항목이 몇 개인지 바로 알려 줍니다.

| 결과 | 뜻 |
| --- | --- |
| `연결됨 · 접근 가능한 항목 N개` | 준비 완료 |
| `공유된 페이지가 0개입니다` | 5번이 아직 안 됐습니다 |
| `토큰이 올바르지 않습니다` | 토큰을 다시 복사해 주세요 |

### 읽기 전용입니다

호출하는 API는 아래 넷뿐이며, 쓰기·삭제 호출은 코드에 존재하지 않습니다.

```
GET  /users/me
POST /search
GET  /blocks/{id}/children
POST /databases/{id}/query
```

### 하는 일

- **계층 구조 유지** — 하위 페이지가 있으면 같은 이름의 폴더가 노트 옆에 생깁니다
  (노션 공식 내보내기와 같은 모양)
- **데이터베이스** — 항목 하나하나가 노트가 되고, 속성은 Frontmatter로 들어갑니다.
  전체 목록을 담은 색인 노트도 함께 만듭니다
- **첨부 전부** — 이미지 · 파일 · PDF · 동영상 · 오디오를 `attachments/` 로 내려받습니다
- **페이지 링크** — 노션의 페이지 멘션과 하위 페이지 링크가 옵시디언 위키링크 `[[...]]` 가 됩니다
- **스마트 증분 동기화** — 노션의 초 단위 최종 수정 시간(`last_edited_time`)을 대조하여, **신규 페이지는 새로 생성**하고, **수정된 페이지만 선별하여 업데이트**합니다. 내용이 바뀌지 않은 페이지는 블록 API 호출과 첨부 다운로드를 완전히 건너뛰어 초고속으로 완료됩니다.

### 지원하는 블록

문단 · 제목1~3 · 글머리 기호 · 번호 목록 · 할 일 · 토글 · 인용 · 콜아웃 · 코드 ·
수식 · 구분선 · 이미지 · 파일 · PDF · 동영상 · 오디오 · 북마크 · 임베드 · 표 ·
다단(컬럼) · 동기화 블록 · 하위 페이지 · 페이지 링크

서식은 **굵게** · *기울임* · ~~취소선~~ · `코드` · 밑줄 · 링크 · 인라인 수식까지 옮깁니다.
토글은 옵시디언의 접이식 콜아웃(`> [!note]-`)이 됩니다.

## 엑셀 탭

### 준비물

없습니다. **[파일 추가]** 로 `.xlsx` 파일을 고르면 됩니다. 여러 개를 한 번에 골라도 됩니다.

**[파일 확인]** 을 누르면 옮기기 전에 무엇이 들어 있는지 알려 줍니다.

```
파일 1개 · 시트 494개 → 노트 494개 · 폴더 2개 (DAILY REPORT, Visit WEEK) · 그림 68개
```

### 하는 일

- **시트 하나 = 노트 하나**
- **비슷한 시트끼리 폴더로** — 이름 끝의 번호·날짜를 떼어 묶습니다.
  `DAILY REPORT (20260824)` 와 `DAILY REPORT (20260820)` 은 `DAILY REPORT/` 폴더로 들어가고,
  `CONTACT POINT` 처럼 혼자뿐인 시트는 폴더 없이 그대로 둡니다
- **표는 표로, 글은 글로** — 보통은 마크다운 표로 옮기지만, 칸에 든 글이 길어
  표로는 읽기 어려운 시트는 `**항목 이름**: 값` 형태의 문단으로 폅니다
- **병합된 칸 정리** — 병합 때문에 생긴 빈 행·열을 걷어내 원래 보던 모양에 가깝게 만듭니다
- **그림 꺼내기** — 시트에 박힌 그림을 `attachments/` 로 꺼내 노트에 붙입니다
- **통합문서 색인** — 파일마다 전체 시트를 묶음별로 훑는 색인 노트를 함께 만듭니다

### 셀 값이 바뀌는 규칙

| 엑셀 | 노트 |
| --- | --- |
| 날짜 (시각 0시) | `2026-08-24` |
| 날짜 + 시각 | `2026-08-24 14:30` |
| `35.0` | `35` (소수점이 의미 없으면 정수로) |
| 셀 안 줄바꿈 | 표에서는 `<br>`, 문단에서는 진짜 줄바꿈 |
| `TRUE` / `FALSE` | `예` / `아니오` |

수식이 든 칸은 **엑셀이 마지막으로 저장한 계산 결과**를 씁니다.

## 결과물 구조

```
볼트/
├── 네이버블로그/
│   ├── 여행/                       # 카테고리 이름 그대로
│   │   ├── 첫 배낭여행.md          # 파일 이름은 글 제목 그대로
│   │   └── 교토에서 사흘.md
│   ├── 개발/
│   │   └── 파이썬 정규식 정리.md
│   ├── 미분류/                     # 카테고리 없는 글
│   ├── 카테고리 - 여행.md          # 자동 생성 색인 (폴더 옆에)
│   ├── 카테고리 - 개발.md
│   ├── attachments/
│   │   └── 223456789_1.jpg
│   └── posts_index.json
├── 노션/
│   ├── 업무 노트.md
│   ├── 업무 노트/                  # 하위 페이지들
│   │   ├── 회의록.md
│   │   └── 회의록/
│   │       └── 상반기 회고.md
│   ├── 독서 기록.md                # 데이터베이스 색인
│   ├── 독서 기록/
│   │   └── 어떤 책 제목.md         # 항목 하나 = 노트 하나
│   └── attachments/
└── 엑셀/
    ├── 주간보고.md                 # 통합문서 색인
    ├── DAILY REPORT/               # 이름이 비슷한 시트끼리
    │   ├── DAILY REPORT (20260824).md
    │   └── DAILY REPORT (20260820).md
    ├── CONTACT POINT.md            # 혼자뿐인 시트는 폴더 없이
    └── attachments/
```

제목이 겹치면 뒤에 `(2)` 를 붙여 구분합니다. 폴더가 달라도 옵시디언 `[[링크]]` 는
이름으로 이어지므로, 노트 이름은 볼트 전체에서 겹치지 않게 맞춥니다.

## 알아 둘 점

### 저장 용량
- 네이버: 글당 이미지 10~50장, 원본 화질은 장당 0.4~1.2MB → 글이 많으면 수 GB가 됩니다
- 노션: 첨부가 많으면 마찬가지입니다. 필요 없으면 옵션에서 체크를 해제하세요

### 걸리는 시간
- 네이버: 글 하나에 약 1초. 이미지는 8개씩 동시에 받습니다
- 노션: API 제한(초당 3회)을 지키느라 노트 하나에 약 1초입니다
- 엑셀: 시트 500개가 10초쯤 (네트워크를 타지 않아 빠릅니다)

### 첨부를 못 받았을 때
- 노션에서 끝내 못 받은 첨부는 `_받지못한첨부.txt` 에 목록이 남습니다.
  그 노트만 지우고 다시 실행하면 해당 노트를 새로 가져옵니다
- 노션 첨부 주소는 약 1시간이면 만료되므로, 페이지를 읽자마자 바로 내려받습니다

### 유튜브·웹페이지 링크
- 동영상 블록에 유튜브·비메오 주소를 넣었다면 파일이 아니므로
  `[영상 보기](주소)` 링크로 남습니다
- 노션에 직접 올린 파일만 볼트로 내려받습니다

### 토큰 보관
- 노션 토큰은 `settings.json` 에 평문으로 저장됩니다.
  이 파일은 `.gitignore` 에 있어 깃에 올라가지 않지만, PC를 공유한다면 주의하세요

### 네이버 스킨별 HTML 차이
- 신버전(SmartEditor ONE)과 구버전(SmartEditor 2)은 구조가 다를 수 있습니다
- 본문·제목·날짜가 비어 나오면 크롬 F12로 실제 셀렉터를 확인하고
  `obsidian_migrator.py` 의 `SELECTORS` 를 수정하세요

## exe 로 만들어 쓰기 (파이썬 없는 PC 에서)

```bash
pyinstaller --windowed --onefile --name obsidian_migrator --hidden-import selenium.webdriver.chrome.webdriver --hidden-import selenium.webdriver.chrome.service --hidden-import selenium.webdriver.chrome.options obsidian_migrator.py
```

저장소 루트에 최신 `obsidian_migrator.exe`가 포함되어 있습니다. 직접 다시 빌드하려면 위 명령어를 실행하세요.

## 구성

| 파일 | 역할 |
| --- | --- |
| `obsidian_migrator.py` | GUI + 네이버 블로그 수집 |
| `notion_importer.py` | 노션 수집 · 블록→마크다운 변환 |
| `excel_importer.py` | 엑셀 시트→노트 변환 |
| `migrator_common.py` | 공통 (중단 신호) |
